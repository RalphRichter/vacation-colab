# Vacation Colab

Collaborative vacation planning web app. The first MVP focuses on hotel discovery, voting and ranking.

## MVP

- Mauritius starter trip with 15 hotel candidates
- Hotel cards and source links
- Yes / Maybe / No voting
- Filtered shortlist
- Drag-and-drop ranking on desktop
- Comparison view
- Add hotel by URL
- Browser persistence via localStorage
- Responsive mobile layout

## Roadmap

1. Automatic hotel website extraction and normalization
2. Trip members and separate votes per traveler
3. Hotel images, prices, room types and cancellation policies
4. Backend persistence and authentication
5. Price monitoring
6. Flights, activities and restaurants
7. Native app

## Run locally

Open `index.html` directly in a browser or serve the folder with any static web server.
